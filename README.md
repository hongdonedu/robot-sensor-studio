# 센서 탐험대 스튜디오

6학년 실과 7단원 「로봇과 융합 기술」 5/9차시 공개수업(2026. 11. 4.)용 웹앱입니다.
네오봇에듀 SMART의 센서 4종(적외선·빛·소리·접촉)을 체험하고, 센서로 만들 로봇 아이디어를 떠올려 우리 반 전시관에 모읍니다.

- `index.html` 수업 허브: 만나기 → 1 센서 알아보기 → 2 센서 탐험(예측·관찰·설명) → 3 아이디어 떠올리기 → 4 아이디어 전시관 → 5 돌아보기
- `assets/` 마스코트·배너 그림(ChatGPT 생성)
- `config.js` 전시관 저장소 연결 주소 한 줄 + 선생님 비밀번호
- `apps-script/Code.gs` 전시관 저장소(구글 시트) 코드

탐험 기록·돌아보기는 각 태블릿(localStorage)에만 저장되고, 아이디어와 반응만 선생님 구글 시트에 저장됩니다.

## ① 인터넷 주소 만들기 (GitHub Pages)
1. GitHub에서 새 저장소 `robot-sensor-studio` 를 **Public**으로 만들기
2. **Add file → Upload files** → 이 폴더 **안의** 파일·폴더를 모두 끌어다 놓기 → **Commit changes**
3. **Settings → Pages → Branch: main / (root) → Save** → 1~2분 뒤 `https://아이디.github.io/robot-sensor-studio/`

## ② 공유 전시관 연결 (3분)
1. 새 구글 시트를 만들고 **확장 프로그램 → Apps Script**
2. 원래 코드를 지우고 `apps-script/Code.gs` 내용을 통째로 붙여 넣기 → 저장
3. **배포 → 새 배포 → 웹 앱** (실행 사용자: 나 / 액세스: 모든 사용자) → 배포 → 권한 승인
4. 웹 앱 URL을 `config.js` 의 `BOARD_API_URL` 에 붙여 넣고, `index.html` 의 `config.js?v=1` 을 `v=2` 로 바꾸기

연결 전에는 '미리보기 모드'(그 태블릿 안에만 저장)로 동작하므로 혼자 연습해 볼 수 있습니다.

## 수업 중
- 아이들에게는 주소 하나만 주면 됩니다. **선생님 메뉴(비밀번호 2022) → 접속 QR**을 화면에 띄우세요.
- 선생님 모드에서는 전시관의 아이디어를 숨기거나, 아이디어 전체를 표로 복사(시트에 붙여넣기)할 수 있습니다.
- 다음 반이 쓰기 전에 **선생님 메뉴 → 이 태블릿 기록 지우기**.
